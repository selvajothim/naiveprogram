# Intelligent Plagiarism Detection System

## Overview
This project is a Python-based plagiarism detection system that uses multiple pattern searching algorithms to identify matching text patterns efficiently.

The system compares algorithm performance using graphical analysis.

---

## Algorithms Used
- Naive Pattern Matching
- KMP Algorithm
- Rabin-Karp Algorithm
- Boyer-Moore Algorithm

---

## Features
- Pattern matching detection
- Character comparison analysis
- Execution time measurement
- Memory usage analysis
- Graphical performance comparison
- Complexity analysis

---

## Technologies Used
- Python
- Matplotlib
